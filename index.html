Beta Version — For Testing and Feedback

CaseLines Bundler is currently provided as a Beta version for testing by selected users and for the purpose of obtaining feedback and identifying errors or improvements.

The application is designed to assist users in organising Court Online documents into a CaseLines-ready structure. It uses automated document recognition, filing-date and filing-time extraction, document classification, sorting and folder allocation.

Because the application performs automated processing, errors may occur. These may include incorrect document-type identification, incorrect filing dates or times, incorrect CaseLines classifications, incorrect ordering, incorrect filenames or other errors.

The application does not replace professional judgment or review. Users are responsible for checking and verifying the output before relying upon it, submitting it to a court, uploading it to CaseLines, or otherwise using it for any legal or professional purpose.

Privacy and POPIA

Local processing of documents

CaseLines Bundler is designed to process uploaded PDF documents locally on the user's computer, within the user's web browser.

The PDF documents selected by the user are not uploaded by CaseLines Bundler to a server operated by the application and are not intentionally transmitted to the developer for storage or processing.

The application processes the documents in the user's browser in order to identify document types, extract filing dates and times, classify documents, rename documents and prepare the CaseLines bundle.

The application does not intentionally retain the uploaded PDF documents after processing has been completed.

POPIA

Because the application is designed so that the user's documents remain on the user's computer and are processed locally in the user's browser, the developer does not receive, collect or retain the personal information contained in those documents through the operation of the application.

Accordingly, the application is designed so that the developer does not itself undertake the remote collection or storage of the personal information contained in the documents uploaded by the user.

Users remain responsible for their own handling of personal information and confidential information, including ensuring that they are authorised to access, process and use the documents and that their use of the application complies with any applicable legal, professional, confidentiality, court or organisational requirements.

Important: This statement describes the intended technical operation of the application. It should not be interpreted as legal advice or as a determination that any particular use of the application is exempt from POPIA or any other applicable law.

Important — Save Your Bundle

The application does not retain the PDF documents after processing.

Once the CaseLines ZIP file has been generated, the original PDFs and the generated bundle are not stored by the application for later retrieval.

You must save the generated ZIP file to your computer before leaving the page or closing your browser.

If you leave the page, close the browser, refresh the page, or otherwise lose the generated file, the application will not be able to retrieve or restore the bundle for you.

User Responsibility

CaseLines Bundler is an assistance and document-organisation tool.

The user remains responsible for:

  • verifying every document's Court Online document type;
  • verifying every filing date and filing time;
  • verifying the chronological order of documents;
  • reviewing all Provisional — Review Required classifications;
  • correcting classifications where necessary;
  • verifying filenames and CaseLines section allocations;
  • ensuring that all required documents have been included;
  • ensuring that no documents have been omitted;
  • ensuring that the resulting bundle complies with the applicable CaseLines requirements; and
  • verifying the final ZIP file before uploading or using it.

No output generated by CaseLines Bundler should be treated as automatically correct merely because the application has classified or processed it.
